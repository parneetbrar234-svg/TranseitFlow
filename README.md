# TRANSITFLOW

TRANSITFLOW is a bus transit website created using HTML, CSS, and JavaScript. The project displays bus timings, available buses, seat availability, and route information through a modern and user-friendly interface.

## Features
- Bus timing display
- Seat availability status
- Route search section
- Interactive UI using JavaScript
- Modern transit themed design
- Multiple bus information cards

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
This project was created to practice frontend web development and improve my skills in designing modern website interfaces.
